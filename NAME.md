# On the name "Matryoshka" — naming, trademark, conflicts

## Legal status of the name

- "Matryoshka" is a common noun (generic word) in English and Russian, like
  "accordion" or "balalaika". Generic words **cannot be exclusively
  appropriated** by anyone; trademarking "Matryoshka" alone for a general
  software class is effectively impossible for anyone.
- In ML the word is already a public concept (matryoshka representation
  learning, matryoshka diffusion, matryoshka quantization). Prior usage is
  broad and academic; a research use of the word infringes nobody.
- **Check done:** the existing ML usage (Matryoshka Representation Learning
  and derivatives) refers to nested *embedding dimensionality* — a different
  concept from our nested *memory substrate*. No project conflicts by name in
  the MCP/agent-tools space as of 2026-08. GitHub search shows no established
  "matryoshka memory" project.
- The combination **"Matryoshka MMI"** is distinctive (name + acronym).

## Trademark: do or don't?

- **Not now.** Filing a trademark costs real money, protects mainly against
  product impersonation, and matters only when the project has users worth
  confusing. At 0 users, a patent/trademark is cost without benefit.
- **Prior art problem (important):** the idea has been publicly disclosed
  (GitHub, Zenodo DOI 10.5281/zenodo.22133160, 2026-06-26). A patent filed
  AFTER public disclosure would be invalid in most jurisdictions, and
  disclosure destroys novelty. Patenting now is not viable; protect priority
  by DOIs and timestamps instead — which we already do (Zenodo + CITATION.cff).

## Nobody gets hurt check

- The Apache-2.0 code is original (verify: no copied MCP SDK code — our server
  is written from scratch against the public protocol).
- The name does not clash with existing trademarks in software class 9/42
  (spot-check: no notable "Matryoshka" software trademark active; russian
  nesting-doll producers hold none in class 9).
- Cultural use of "matryoshka" is respectful and descriptive, not
  appropriative; attribution to the folk craft origin is natural.

## Conclusion

Keep the name. Use the full form **Matryoshka MMI** in the product and
**Matryoshka (MMI)** in papers. Rely on DOI/Zenodo for priority, not patents.
Optionally, register the domain matryoshka.dev later if the project grows.
